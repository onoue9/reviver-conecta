# Acessibilidade — Reviver Conecta (MVP)

Avaliação feita em 17/11/2026 no app rodando localmente (`ng serve` com os emuladores do Firebase e dados fictícios).
Ambiente: Chromium headless, viewport de celular 390 × 844 com escala 2 (`deviceScaleFactor: 2`).

## Nota automática (Lighthouse 13.6.0, categoria Acessibilidade, perfil mobile)

| Página                  | URL                               | Nota    |
| ----------------------- | --------------------------------- | ------- |
| Cursos                  | `/cursos`                         | **100** |

Os relatórios completos estão em [`lighthouse-cursos.html`](lighthouse-cursos.html) e [`lighthouse-inscricao.html`](lighthouse-inscricao.html).

> **Atenção:** o Lighthouse (que usa o axe-core) só verifica o que dá para checar automaticamente. A nota 100 **não** garante que a interface é acessível: os problemas que estavam presentes antes das correções passaram despercebidos pela ferramenta e foram encontrados em testes manuais.

## O que ainda falta

1. **Sem link "pular para o conteúdo".** Quem usa teclado precisa passar pelos 3 links da barra em toda página.
2. **Mudança de tela após a inscrição não move o foco.** O cartão de resultado tem `role="status"`, mas o foco não vai para ele, e **não foi testado com leitor de tela** (NVDA, TalkBack ou VoiceOver).
3. **Sem tema escuro.** O tema força `color-scheme: light`.

## Observação sobre as capturas

- O campo de data aparece como `mm/dd/yyyy` nas capturas porque o Chromium headless do teste usa o formato regional padrão do container; num navegador configurado em português aparece `dd/mm/aaaa`.
- Todos os nomes nas capturas são fictícios, criados só para este teste.
